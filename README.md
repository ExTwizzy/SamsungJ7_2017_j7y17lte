# Samsung Galaxy J7 (2017) – Exynos 7870

A collection of custom Android development files and tools for the **Samsung Galaxy J7 (2017)** powered by the **Exynos 7870** chipset.

**Device:** Samsung Galaxy J7 (2017)  
**Model:** SM-J730F / J7Y17LTE  
**Platform:** Exynos 7870  
**Architecture:** ARM64

## Repository Contents

This repository contains the following files and resources:

- **TWRP Recovery** – Custom Team Win Recovery Project for installing custom ROMs and managing device partitions.
- **LineageOS 18.1** – Unofficial Android 11-based custom ROM for the Galaxy J7 (2017).
- **Vendor Creator** – Tools and scripts for creating or preparing vendor images required by custom ROMs.
- **GApps** – Google Apps packages compatible with the supported Android version.

## Purpose

The goal of this repository is to collect essential files needed for custom ROM installation, system recovery, and Android development on the Samsung Galaxy J7 (2017).
